# Viper's Gambit

A snake card game made with [LÖVE](https://love2d.org) 11.x.

## Install LÖVE

**Mac**
```bash
brew install --cask love
```

**Windows**
```bash
winget install OpenJS.LOVE
```

No `winget`? Download the Windows installer from https://love2d.org and run it.

**Linux** (Ubuntu or Debian; other distros: https://love2d.org)
```bash
sudo apt install love
```

## Run

```bash
git clone https://github.com/JamieLandolt/vipers-gambit
cd vipers-gambit
love .
```

On Mac, if `love` is not found: `open -n -a love .`
On Windows (PowerShell), if `love` is not found: `& "C:\Program Files\LOVE\love.exe" .`
